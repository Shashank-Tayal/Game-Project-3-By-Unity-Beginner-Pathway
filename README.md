# Endless Runner (Farmer Runner)

## 🧠 Technical Skills Applied
* **Object Instantiation:** Dynamically spawning obstacles with randomized intervals.
* **Physics & Collisions:** Utilizing Unity's Rigidbody system and Box Colliders for jumping and crash detection.
* **Animation Controllers:** Managing state transitions (Run, Jump, Death) using Animator parameters and triggers.
* **Component Communication:** Triggering game-over states across multiple scripts via object references.
* **Visual Effects:** Implementing Unity Particle Systems for dirt trails and explosion effects.

---

## 🎮 Gameplay Overview
Take control of the farmer running through a continuous countryside landscape. Dodge incoming obstacles by timing your jumps accurately, maintain your run for as long as possible, and aim for the highest score.
